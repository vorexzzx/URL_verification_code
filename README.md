
# URL Analiz ve Güvenlik Aracı

Bu proje, Python ve Tkinter kullanılarak geliştirilmiş, verilen bir URL'nin yönlendirme trafiğini ve güvenlik risklerini analiz eden bir masaüstü uygulamasıdır.

## Özellikler
* Yönlendirme (Redirect) zinciri takibi.
* HTTPS güvenlik kontrolü.
* URL kısaltma servislerinin tespiti.
* Kullanıcı dostu arayüz.

## Kurulum
1. Projeyi bilgisayarınıza indirin.
2. Gerekli kütüphaneyi yükleyin: `pip install requests`
3. Uygulamayı çalıştırın: `python linkcheck.py`


URL Analysis and Security Tool
This project is a desktop application developed using Python and Tkinter that analyzes the redirect traffic and security risks of a given URL.

Features
Redirect chain tracking.
HTTPS security check.
Detection of URL shortening services.
User-friendly interface.
Installation
Download the project to your computer.
Install the necessary library:`pip install requests`
Run the application: `python linkcheck.py`
